What is this project?

BeatTheBookie is an academic research repository built around the analysis of football betting-market data. The project investigates whether bookmaker odds can contain measurable pricing patterns and provides code and datasets for reproducing parts of the published analysis.

880,494football matches in the historical closing-odds dataset
31,074matches in one continuous odds-series dataset
82,786matches in the later odds-series dataset

The paper

Beating the bookies with their own numbers — and how the online sports betting market is rigged was published as arXiv:1710.02824 in 2017. The repository contains code intended to reproduce the historical figures and analysis described by the authors.

Dataset

The repository documents several football datasets covering matches, bookmaker odds, and changes in odds over time. The largest datasets are distributed separately because the SQL dumps are very large.

Core tables

matches — league, teams, result and match date.

odds_history — bookmaker, bet type, outcome and status.

odds_history_series — the time series of offered odds and timestamps.

Analysis code

The repository contains Python and MATLAB analysis scripts, plus PHP/SQL utilities for generating CSV data from the databases.

Reproducibility

The original project was designed for MATLAB/Octave and later includes Python scripts. Running the full historical analysis requires the corresponding datasets and, for some workflows, a MySQL database import.
